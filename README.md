# Portal de Segurança Bancária — TRUST GUARD

**Objetivo:**  

Criar um site informativo e educativo que oriente usuários sobre os principais golpes no cenário bancário com medidas de proteção, coleta de relatos de fraudes e integração com inteligência artificial.  
O projeto será desenvolvido como avaliação A3, e contará com:

-  **Informações educativas** sobre os principais golpes e fraudes bancários e como se prevenir  
-  **Chat inteligente com IA** para tirar dúvidas sobre segurança bancária
-  **Formulário de relatos** os usuários poderão reportar golpes que já presenciaram para coleta de relatos   
-  **Banco de dados estruturado** para armazenar e analisar os relatos  

---

## Tecnologias Utilizadas até o momento

| Camada | Tecnologias | Função |
|---------|--------------|--------|
|  **Frontend** | HTML / CSS / JavaScript / React | Interface e interação com usuário |
|  **Backend (API)** | Spring Boot | Criação de APIs REST e Integração com IA |
|  **IA Integrada** | Spring AI + OpenAI API | Chat educativo sobre segurança bancária |
|  **Banco de Dados** | PostgreSQL | Armazenamento de relatos de fraude |
|  **Versionamento** | Git / GitHub | Controle de código e colaboração |
